# 🏋️ GymPro – Gym Membership Management System

GymPro is a full-stack web application designed to help gyms manage their members and everyday membership operations.

The project was built as a complete software engineering project, combining a FastAPI backend, PostgreSQL database and a responsive web interface.

## 🚀 Features

- Member registration and management
- Member search and filtering
- QR code generation for each member
- JWT-based authentication
- Secure login system
- Account lockout after multiple failed login attempts
- API rate limiting
- Automated welcome emails
- Membership management dashboard
- Responsive interface for desktop and mobile devices

## 🛠️ Tech Stack

### Backend
- Python
- FastAPI
- PostgreSQL
- REST API
- JWT Authentication

### Frontend
- HTML
- CSS
- JavaScript
